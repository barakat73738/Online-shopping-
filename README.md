# Online-shopping-
## 1. Planning Phase
The system allows users to view products, add items to a cart, and checkout online.
## 2. Requirement Analysis
Functional requirements include product viewing, cart management, and checkout. Non-functional requirements include usability and efficiency.
## 3. System Design
The system is designed using HTML, CSS, and JavaScript with modular components.
## 4. Implementation
The system is implemented using frontend web technologies.
## 5. Testing
All features were tested and confirmed working.
## 6. Deployment
The system can be deployed using GitHub Pages.
## 7. Maintenance
Future updates may include database and payment integration.
